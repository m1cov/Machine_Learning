_______________Windows_____________________________________________
1. Отворете терминал на anaconda (windows) и променете ја локацијата на исто место каде што се наоѓа mlenv.yml датотеката
	пр: cd C:\Users\"user_name"\Downloads
2. Извршете ја следната команда:
	conda env create -f mlenv.yml
3. Секој пат пред да отворите jupyter lab активирајте ја околината MLenv
	conda activate mlenv
